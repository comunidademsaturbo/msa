# MSA Turbo — versão 3 (arquivos na raiz)

Extraia o ZIP. Selecione todos os arquivos extraídos e envie para a **raiz** do repositório GitHub Pages. Substitua `index.html`, `styles.css`, `script.js` e `config.js`; inclua as novas imagens PNG. Fotos JPEG e MP4 antigos continuam necessários. Não envie apenas o ZIP.

## Configurar os botões antes de anunciar

Abra `config.js` e preencha `oneYear` com o checkout Kiwify de R$ 497, `twoYears` já está configurado com o checkout de R$ 597 e `whatsapp` com o atendimento. Até preencher, esses botões exibem um aviso. Confira as condições de parcelamento de cada oferta diretamente nos respectivos checkouts.

A página contém o vídeo YouTube solicitado, a gravação de tela de depoimentos, uma galeria com os 12 prints PNG originais de resultados, mais três montagens de relatos, a garantia de 7 dias, cards de módulos e uma janela de saída que aparece uma vez por sessão (desktop: saída pelo topo; celular: após 45% da rolagem). Verifique se os novos PNGs aparecem no repositório na mesma pasta do `index.html`.
